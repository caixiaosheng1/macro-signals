# 宏信号

给自己看的宏观判断笔记。静态页面，手机浏览器或微信里打开即可。

线上地址：<https://caixiaosheng1.github.io/macro-signals/>

## 更新内容

只改 `data.js`，保存后推送到 `main`。不要把练习用的示例留在数组里。现在的数组是空的，页面会显示「暂无内容，等待第一篇访谈」。

字段含义、枚举原词、以及「加一篇访谈」的顺序，都写在 `data.js` 开头。简表如下：

1. 嘉宾写入 `GUESTS`。
2. 访谈写入 `INTERVIEWS`，`guestId` 对上嘉宾。
3. 值得以后核对的说法拆进 `SIGNALS`，日期用访谈发布日。
4. 若干信号若指向同一件大事，把它们的 id 写入 `THEMES`。
5. 若形成可跟踪的推演，写入 `OPPORTUNITIES`：成功率、盈亏比、何时动手、什么情况下算错。
6. 把 `SITE.updated` 改成当天北京时间，例如 `2026-03-18 21:30 (北京时间)`。

方向、状态、结果必须用 `data.js` 注释里的中文原词，筛选才对得上。首页的主线和机会按数组顺序各显示前 5 条；信号按日期取最新 5 条。

推送到 `main` 后，GitHub Pages 通常一两分钟内更新。手机上若还是旧页面，关掉重新打开。

## 页面

首页、时间线、机会、访谈、嘉宾。手机用底部导航，宽屏用顶部导航。右上角（手机上在标题下方）的搜索只查信号和访谈。

## 发布

从 `main` 分支的仓库根目录用 GitHub Pages 发布，不经过 Jekyll，也不使用 Actions。根目录的 `.nojekyll` 就是为这个准备的。

嘉宾观点不是事实。本站推演只供参考，不构成买卖建议，也没有接入实时行情。
